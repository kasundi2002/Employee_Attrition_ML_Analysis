# Employee Attrition Prediction using Machine Learning

## 📌 Project Overview

Employee attrition is a critical issue in organizations as it affects productivity, costs, and team stability. This project aims to predict whether an employee is likely to leave the company using machine learning techniques.

We use the IBM HR Analytics dataset to build predictive models and analyze the key factors influencing employee attrition.

---

## 🎯 Objectives

* Predict employee attrition (Yes/No)
* Compare multiple machine learning algorithms
* Identify key factors influencing attrition
* Provide business insights based on model results

---

## 📊 Dataset

* **Source:** IBM HR Analytics Dataset (Kaggle)
* **Link:** https://www.kaggle.com/datasets/pavansubhasht/ibm-hr-analytics-attrition-dataset
* Contains employee-related information such as:

  * Age, Salary, Job Role
  * Job Satisfaction
  * Overtime
  * Work Experience
  * Attrition (Target Variable)

---

## 🧠 Machine Learning Algorithms Used

1. Logistic Regression
2. Decision Tree
3. Random Forest
4. Support Vector Machine (SVM)

---

## ⚙️ Project Workflow

1. Data Preprocessing

   * Handling missing values
   * Encoding categorical variables
   * Feature scaling

2. Exploratory Data Analysis (EDA)

   * Understanding feature distributions
   * Identifying patterns related to attrition

3. Model Training

   * Train 4 different ML models

4. Model Evaluation

   * Accuracy
   * Precision
   * Recall
   * F1-score
   * Confusion Matrix

5. Model Comparison

   * Compare performance of all models

---

## 📈 Results

* Performance of each model is evaluated using classification metrics
* Confusion matrices are used to visualize predictions
* Best performing model is identified

---

## 🔍 Key Insights

* Identify most important features influencing attrition
* Analyze factors such as:

  * Overtime
  * Monthly Income
  * Job Satisfaction
